```bash
│ 0   │ ⭐ 앱이 실제로 쓴 시간(ms) (upstream service time) │
```


retries: {attempts: 3, retryOn: 5xx, perTryTimeout: 2s} 해석

```bash
┌─────────────────┬────────────┬─────────────────────────────────────────────┐
│      항목       │     뜻     │                   풀어서                    │
├─────────────────┼────────────┼─────────────────────────────────────────────┤
│                 │ 언제       │ 응답이 5xx(서버 에러: 500/502/503 등)일     │
│ retryOn: 5xx    │ 재시도?    │ 때만. 404 같은 4xx(내 잘못)는 재시도 안 함  │
│                 │            │ — 다시 보내도 똑같으니까                    │
```
