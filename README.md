# Dev Study Club — 글 쓰는 법

스터디 진도와 학습 노트를 남기는 곳입니다. **글은 전부 `content/` 안에 있고, 마크다운만 쓰면 됩니다.**
커밋해서 push하면 GitHub Actions가 알아서 배포합니다.

```
content/
└── istio-in-action/          # 책(스터디) 하나
    ├── members.json          # 참여자 목록
    ├── chapters.md           # 책 목차 — 다 같이 읽으므로 하나만 있으면 된다
    ├── schedule.md           # 주차별 일정
    └── <이름>/
        └── <장번호>.md        # 학습 노트 ← 주로 쓰는 파일
```

## 1. 학습 노트 쓰기

공부를 마친 챕터 번호로 파일을 만듭니다. **파일을 만드는 것 자체가 그 챕터를 완료했다는 표시**입니다.
따로 체크할 게 없습니다.

```
content/istio-in-action/성수/1.md      ← 성수가 1장을 끝냈다
```

파일을 만들면 `/note/성수/1` 주소에서 글로 열립니다. 챕터 목록에서 그 장을 누르면 이 주소로 갑니다.

### 쓸 수 있는 것

제목, 목록, 표, 링크, 인용, 코드 블록 등 일반 마크다운을 그대로 씁니다.

````markdown
## 핵심 개념

- **서비스 메시**: 네트워킹 관심사를 인프라로 옮긴다
  - 사이드카 프록시가 트래픽을 가로챈다

> 클라우드에서는 인프라가 일시적이라는 가정으로 앱을 만든다

| 패턴          | 하는 일                           |
| ------------- | --------------------------------- |
| 서킷 브레이커 | 오동작하는 서비스에 부하를 끊는다 |

```bash
istioctl install --set profile=demo -y
```

[Istio 공식 문서](https://istio.io)
````

### 이미지 넣기

이미지는 `public/images/notes/<책>/`에 두고, **`images/`부터 시작하는 경로**로 씁니다.

```markdown
![서비스 메시 개념도](images/notes/istio-in-action/1-1.png)
```

파일명은 `<장번호>-<순번>.png`처럼 어느 장 것인지 알 수 있게 지어주세요.

### 알아두면 좋은 것

- 노트는 서식을 자유롭게 써도 됩니다. 다른 파일과 달리 포맷 검사를 받지 않습니다.
- 마크다운 안에 `<script>` 같은 걸 넣어도 렌더 전에 걸러지므로 안전합니다.
- 노트를 안 써도 진도 화면은 항상 정상 동작합니다.

## 2. 목차 고치기 — `chapters.md`

챕터와 절 제목이 여기서 나옵니다. 홈 화면의 챕터 이름, 노트 화면의 제목이 이 파일을 따릅니다.
**같은 책을 함께 읽으므로 책마다 하나만 있으면 됩니다** — 사람별로 복사하지 않습니다.

```markdown
# Istio in Action 학습 진도

## 1장. 서비스 메시 소개

- [ ] 1.1 더 빨리 가려 할 때 마주치는 어려움
- [ ] 1.2 애플리케이션 라이브러리로 해결하기
```

`## `로 시작하는 줄이 챕터, `- [ ] `로 시작하는 줄이 절입니다. 완료 여부는 노트 파일이 있는지로
정해지므로 체크 표시(`[ ]`/`[x]`)는 손대지 않아도 됩니다.

## 3. 일정 바꾸기 — `schedule.md`

표를 고치면 날짜에 맞는 "오늘의 퀘스트"가 자동으로 바뀝니다.

```markdown
| 기간                    | 챕터 | 소주제                   |
| ----------------------- | ---- | ------------------------ |
| 2026-07-13 ~ 2026-07-19 | 1, 2 | 서비스 메시와 Istio 시작 |
```

날짜는 `YYYY-MM-DD`, 챕터는 `1, 2`처럼 쉼표로 두 개를 씁니다.

## 4. 사람 추가하기 — `members.json`

```json
[{ "name": "성수", "avatar": "avatars/성수.webp" }]
```

배열 순서가 화면에 보이는 순서입니다. 추가할 때 두 가지만 하면 됩니다.

1. `members.json`에 이름·아바타 추가
2. `public/avatars/<이름>.webp` 이미지 넣기 — 카드 폭을 꽉 채우므로 **1000px 16:9**로 준비합니다

> PNG로 받았다면 `cwebp -q 82 <이름>.png -o <이름>.webp`로 바꿔 넣어주세요. 같은 화질에 용량이 1/4입니다.

노트 폴더(`content/istio-in-action/<이름>/`)는 첫 노트를 쓸 때 만들면 됩니다.

## 5. 책(스터디) 추가하기

`content/` 아래에 같은 모양으로 폴더를 하나 더 만들면 됩니다.

```
content/npm-deep-dive/
├── members.json
├── chapters.md
└── schedule.md
```
